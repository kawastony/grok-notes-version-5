# Note 14 — Enlarged fork

**Date:** 2026-10-09
**Status:** Opened, then tested. Not a new packet.

A shared audit scale is not a shared physical mechanism. Note 13 closed Step 1 for the isolated Hamiltonian. The fork that remains is a different theory, one in which the same reduction that fixes m(x) also fixes an odd scalar or a metric factor.

Two enlargements already on the record are the ones that could have done that without a new fit.

1. The packet sources its own Newtonian potential.
2. The cone metric of version 4, notes 60 and 62, whose radial equation is fixed without a galactic constant inserted by hand.

Note 15 tests the first. Note 16 tests the second. Neither fixes an odd scalar. A galactic gradient across the packet remains an environment, not an output of the reduction that fixes m.

## Reopen condition, unchanged

The odd scalar, or the metric factor, has to be fixed by the same data that fix m(x). Supplying it from outside is the import already classified in notes 11 and 12.
