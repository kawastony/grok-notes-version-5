# Note 3 — Translate the criterion, not the object

**Date:** 2026-10-09
**Status:** Audit instrument. Not a bridge.

A shared audit scale is not a shared physical mechanism. This note translates the micro gains into the program's shared vocabulary. It asserts no bridge. Any sentence that reads as one is a homonym or a spec, not a result.

## Operational grades

Derived, fitted, and chosen are method words, not tone.

- **Derived.** Fixed before comparison. No free functional choice at the stage being tested.
- **Fitted.** One or more constants chosen from data, or from a numerical window, inside a form already fixed.
- **Chosen.** The functional form itself was selected rather than forced.

Three grades follow. The old binary, derived versus mapped, is retired.

- **Grade 1 — form derived, constant derived.** Nothing fitted.
- **Grade 2 — form derived, constant fitted.** The shape is forced. A number inside that shape is measured.
- **Grade 3 — form chosen, constant fitted.** The shape was selected. A constant inside it was fitted.
