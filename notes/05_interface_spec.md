# Note 5 — Interface spec

**Date:** 2026-10-09
**Status:** Missing sockets. Not a connection.

A shared audit scale is not a shared physical mechanism. "No bridge" is a negation. This note turns it into a list of sockets. None is populated.

## Macro sockets

| socket | what it would have to carry | state |
|--------|-----------------------------|-------|
| a0 | a dimensionful acceleration, the same for every system | empty |
| mu-form | the interpolator, forced rather than selected | empty |
| a0(z) | epoch dependence of that scale | empty |
| unit map | lattice spacing and an energy unit | empty |
| field coupling | a term in g or grad Phi inside the packet Hamiltonian | empty |

A collaborator on the macro side needs the socket, not the complaint. The plug is missing. The packet does not fill it.

## Why empty is structural

The packet Hamiltonian is H = -i sigma_y d/dx + m(x) sigma_z. It has an energy and a length, both in lattice units. An acceleration needs a time that is the same for every system, and a coupling to the local field. Neither is in H. Surface gravity of a black hole is set by the hole's mass. It is not Delta E.

Filling a socket is an addition. It is not a recovery of notes 45, 54, 57, or 58 of version 4, and it is not a recovery of notes 2 to 4 here.

## Firewall

An empty socket is not a near-connection. Same standard, different grades, no contact. The tax-form analogy in note 3 stands: same form, different firms.
