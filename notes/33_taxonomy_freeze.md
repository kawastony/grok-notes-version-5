# Note 33 — Taxonomy freeze

**Date:** 2026-10-11
**Status:** Four boxes locked. No new calculation.

A shared audit scale is not a shared physical mechanism. This note freezes the separation that the midpoint and integral tools produced. It does not derive a ruler.

## Box A — Topology / container

Static cone. Opening λ. Deficit μ = 2π(1 - λ). Metric ds² = dr² + (λ r)² dφ². Unrolls to flat sector.

Controls: holonomy, image multiplicity for a distant source, global identification.

Does not control: local curvature, inward fall, radial attraction, any speed or length. Geodesics are straight on the unrolling. For J ≠ 0 the radial equation is r̈ = J² / (λ² r³) > 0. The cone is repulsive. Only a radial geodesic (J = 0) reaches the tip.

## Box B — Optical / lapse

Conformal factor on the cone, N(r) = r / (r + ξ), or equivalent. Optical curvature K_opt = -ξ r / (r + ξ)^4 < 0.

Controls: local defocusing, clock rate, propagation. Deficit-blind: λ drops out of K_opt. Cross-checked against the earlier λ-cone formula, which reduces to the same expression at R_0 = 0.

Does not control: image multiplicity. That stays in Box A.

## Box C — Constitutive closure

Fixed circumference, fixed volume, α-dial (lateral response ν in the audit notation). Bookkeeping for how a stretch is recorded. The midpoint identity and the integral ledger live here. They track a closing interval or a trip length. They do not force a constant g.

## Box D — Anchor / scale

Hosted inputs. Fundamental speed c_0, length R_0, deficit μ. The static cone has no time and no preferred length. It cannot produce a speed v or a length d. Count: three parameters against two data (v, d). One input short. The missing piece is external. It is not a gap in the algebra of the cone.

## Standing

Local optics is deficit-blind. Global topology is curvature-blind. The two sectors decouple for the cone family. Fall from the static cone is not merely absent; the geometry is repulsive. Scale is an input, not an output.
